#### b. Use Case Specification

|  |  |  |  |
| :-: | :-: | :-: | :-: |
| UC ID and Name: | UC17 – Upgrade Plan & Buy Credits |  |  |
| Created By: | Lại Hữu Quang Anh | Date Created: | 29/09/2026 |
| Primary Actor: | Tutor, Parent | Secondary Actors: | Payment Gateway |
| Trigger: | Tutor or parent clicks "Upgrade" / "Buy credits" on the dashboard, or is redirected from UC12 / UC14 when credits run out. |  |  |
| Description: | Allows a tutor or parent to buy a credit pack or upgrade from the Free plan to the Pro plan of their role (more connection credits per month, higher AI quota; SMS reminders for tutors) and pay through the Payment Gateway. |  |  |
| Preconditions: | PRE-1: The tutor is logged in. |  |  |
| Postconditions: | POST-1: After a valid payment result, the plan is upgraded or the credits are added and a receipt is stored (UC18). |  |  |
| Normal Flow: | UC17.0 Upgrade Plan & Buy Credits1. System shows the plans (Free, Pro) for the user's role and the credit packs available to that role, with prices configured by Admin (UC39).2. User selects the Pro plan with a duration (months) or a credit pack with a quantity and clicks "Checkout".3. System creates a payment order (BR-06) and redirects the tutor to the Payment Gateway.4. User pays by QR / ATM card / credit card.5. Payment Gateway returns the result (redirect + IPN).6. System verifies the IPN signature, upgrades the plan or adds the credits and shows the Payment Result screen. |  |  |
| Alternative Flows: | A1: Auto-renew Pro1. Before the period ends, System reminds the tutor; the tutor renews with the same flow or the plan returns to Free. |  |  |
| Exceptions: | E1: Payment failed or cancelled→ System shows the failure and allows retrying; nothing is changed.E2: Invalid IPN signature / duplicate order→ System ignores the request and logs it (BR-06). |  |  |
| Priority: | High |  |  |
| Frequency of Use: | Monthly. |  |  |
| zBusiness Rules: | BR-06: Payment orders; Plans per role: Tutor – Free (5 credits/month, basic classroom, email reminders), Pro (30 credits/month, higher AI quota, SMS reminders); Parent – Free / Pro (monthly credits and AI quota configurable in UC39). A user can only subscribe to a plan of their own role. |  |  |
| Screens: | SC20 – Checkout; SC21 – Payment Result |  |  |
